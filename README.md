## 💰 Sistema Financeiro Web - Fluxo de Caixa

Projeto desenvolvido com foco em Back-End em PHP, simulando um Sistema Básico de Controle de Movimentações Financeiras (Fluxo de Caixa).

Este sistema foi criado como estudo avançado de programação nativa em PHP, aplicando boas práticas de desenvolvimento e integração com Banco de Dados MySQL.

---

## 🎯 Objetivo

Desenvolver uma aplicação web completa, capaz de:

- Cadastrar, editar e excluir **movimentações financeiras**.
- Consultar registros com **filtros dinâmicos**.
- Gerar relatórios utilizando **INNER JOIN** em consultas SQL.
- Demonstrar estruturação de camadas de acesso a dados (**DAO**) sem frameworks.
- Garantir uma interface intuitiva e responsiva, utilizando **Bootstrap** como base visual.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5 e CSS3**
- **Bootstrap** para estruturação de layout responsivo
- **JavaScript e jQuery** para interatividade
- **PHP Nativo** para toda lógica de back-end
- **MySQL** como banco de dados relacional
- **SQL avançado** com JOINs, filtros e relatórios
- **DAO (Data Access Object)** para organização e modularização do código
